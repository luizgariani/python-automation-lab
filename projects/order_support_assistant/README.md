# Order Support Assistant

A small Python project that simulates a customer support automation flow for order status inquiries.

## Objective

The goal of this project is to practice Python fundamentals in a scenario connected to customer support automation.

The assistant receives simulated order data, checks the order status and generates a customer-friendly support message.

## Concepts practiced

- Python dictionaries
- Lists of records
- Conditional logic
- Functions
- File organization
- Basic project structure
